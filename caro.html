log(...) của bot hiện ở đây, kèm thời gian suy nghĩ mỗi nước.

    Luật chơi

    • Hai bên lần lượt đặt một quân lên ô trống. Xanh đi trước.
    • Ai có đủ 5 quân liên tiếp (bàn 3×3: 3 quân) theo hàng ngang, dọc hoặc chéo trước thì thắng. Chuỗi dài hơn 5 cũng tính.
    • Bàn kín mà chưa ai thắng là hòa.
    • Chơi tay: chọn “👤 Người chơi” cho một bên rồi bấm vào ô trống khi đến lượt.

    Viết bot

    function getNextMove(state, helpers, log) {
  // state.grid      : ["000..", ...]  '0' trống, '1' Xanh, '2' Đỏ
  // state.myPlayer  : 1 (Xanh) hoặc 2 (Đỏ)
  // state.winLength : số quân liên tiếp để thắng
  // state.legalMoves: [{ to: { r, c } }, ...]  mọi ô trống
  return state.legalMoves[0];   // trả về { to: { r, c } }
}

    helpers: getLegalMoves(player, board), simulateMove(board, move, player), checkWin(board), randomChoice(arr), distance(r1,c1,r2,c2), toNotation(r,c). Python / C++: đọc JSON state từ stdin, in {"to":{"r":R,"c":C}} ra stdout, log ra stderr.

    Mỗi nước có tối đa 2,5 giây (trong trình duyệt: 3 giây). Bot lỗi, quá giờ hoặc đi sai luật sẽ bị thay bằng một nước ngẫu nhiên và báo ở Console.
