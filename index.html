🎮 Hướng dẫn Lập Trình Bot (Bot Coding Guide)

Chào mừng bạn đến với OTTv2 Code Arena! Trò chơi là sự kết hợp giữa Cờ vua và Oẳn Tù Tì trên bàn cờ 9x9. Nhiệm vụ của bạn là lập trình thuật toán trong hàm getNextMove(state, helpers, log) để đưa quân tới đích ở phía đối diện!

🏆 Mục Tiêu Chiến Thắng

Mục tiêu duy nhất để chiến thắng là đưa bất kỳ quân nào tới ô đích ở phía đối diện bàn cờ:

  1. Đội Xanh (Blue): Đưa quân tới ô I9 (góc trên phải).
  2. Đội Đỏ (Red): Đưa quân tới ô A1 (góc dưới trái).

💡 Lưu ý: Ăn quân đối phương theo luật Oẳn Tù Tì nhằm mục đích dọn đường và cản trở đối thủ, chỉ có chạm đích ở phía bên kia mới quyết định chiến thắng!

📜 Luật Di Chuyển & Ăn Quân

  • Mỗi quân có thể đi 1 bước theo 8 hướng (như quân Vua trong cờ vua).
  • Oẳn tù tì: ✊ Đấm ăn ✌️ Kéo | ✌️ Kéo ăn ✋ Lá | ✋ Lá ăn ✊ Đấm.
  • Chặn nhau: Quân cùng loại không thể ăn nhau và không thể đi đè lên nhau. Quân cùng đội không thể đi vào ô nhau.

📦 Cấu Trúc Dữ Liệu state

{
  myPlayer: 1, // 1 (Xanh) hoặc 2 (Đỏ)
  opponentPlayer: 2, // Đối thủ
  myGoal: { r: 0, c: 8 }, // I9 đối với Xanh, A1 đối với Đỏ
  opponentGoal: { r: 8, c: 0 },
  board: Array(9).fill().map(...), // 9x9 bàn cờ. Mỗi ô là { player: 1|2, type: 'rock'|'paper'|'scissors' } hoặc null
  legalMoves: [ // Danh sách tất cả nước đi hợp lệ của bạn lúc này
    {
      from: { r: 5, c: 1 },
      to: { r: 4, c: 1 },
      pieceType: 'rock',
      capture: 'scissors', // Loại quân địch bị ăn (hoặc null nếu đi ô trống)
      notation: 'B4 → B5'
    },
    ...
  ],
  myCounts: { rock: 3, paper: 4, scissors: 3, total: 10 },
  opponentCounts: { rock: 3, paper: 4, scissors: 3, total: 10 },
  moveHistory: [ ... ], // Lịch sử các nước đi từ đầu trận
  turnNumber: 1
}

🛠️ Các Hàm Tiện Ích helpers

Hàm Ý nghĩa
helpers.distance(r1, c1, r2, c2) Tính khoảng cách bước vua (Chebyshev distance).
helpers.canCapture(attacker, defender) Kiểm tra attacker có ăn được defender theo luật oẳn tù tì không.
helpers.simulateMove(board, move) Mô phỏng nước đi và trả về bàn cờ mới (cho thuật toán Minimax lookahead).
helpers.getLegalMoves(player, board) Lấy tất cả nước đi hợp lệ của player trên board.
helpers.randomChoice(array) Chọn ngẫu nhiên 1 phần tử trong mảng.
helpers.toNotation(r, c) Chuyển tọa độ sang ký hiệu cờ (ví dụ: r=4, c=1 thành "B5").

💡 Ví Dụ Bot Cơ Bản

function getNextMove(state, helpers, log) {
    // 1. Nếu có nước chạm đích -> Đi ngay để thắng!
    const winGoal = state.legalMoves.find(m => 
        m.to.r === state.myGoal.r && m.to.c === state.myGoal.c
    );
    if (winGoal) return winGoal;

    // 2. Nếu có nước ăn quân -> Ưu tiên ăn quân đối phương
    const capture = state.legalMoves.find(m => m.capture !== null);
    if (capture) {
        log("Ăn quân địch:", capture.notation);
        return capture;
    }

    // 3. Tiến gần về đích nhất
    return state.legalMoves.sort((a, b) => {
        const dA = helpers.distance(a.to.r, a.to.c, state.myGoal.r, state.myGoal.c);
        const dB = helpers.distance(b.to.r, b.to.c, state.myGoal.r, state.myGoal.c);
        return dA - dB;
    })[0];
}
